# PlantGenealogy

تطبيق WPF عربي لإدارة شجرة نسب نباتية/عائلية باستخدام SQLite، مع تصميم مناسب جدًا لشجرة النسب التفاعلية.

## التشغيل

1. افتح المشروع في Visual Studio 2022.
2. تأكد من تثبيت .NET 8 SDK.
3. من NuGet، سيتم استرجاع الحزمة `Microsoft.Data.Sqlite` تلقائياً.
4. اضغط F5 لتشغيل التطبيق.

## المزايا

- شجرة تفاعلية قابلة للتوسيع
- إضافة عقدة جديدة كجذر أو فرع
- تحديث وحذف العقد
- حفظ البيانات في SQLite
- واجهة عربية مريحة
